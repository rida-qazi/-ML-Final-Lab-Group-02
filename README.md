# -ML-Final-Lab-Group-02
## Dataset

This project uses the RAVDESS Speech Audio dataset.

The raw dataset is not stored in this repository because of its size.

After downloading the dataset, place the RAVDESS folder at:

data/raw/RAVDESS/

Expected structure:

data/
└── raw/
    └── RAVDESS/
        ├── Actor_01/
        ├── Actor_02/
        └── ...
